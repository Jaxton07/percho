## 维护规则（重要）

**每次项目改动完成后，必须检查本索引是否过时**：

- 新增 / 删除 / 重命名文件 → 更新对应「目录结构」或「组件」清单
- 关键导出、函数职责变化 → 更新对应描述
- 改动落到了本索引没覆盖的地方 → 补进速查表

本文件在 `docs/`（**入库共享**），由 `AGENTS.md` 引用。修改代码前读它，改完检查它。排查疑难问题优先看 `docs/PITFALLS.md`（踩坑记录：症状索引 + 事故复盘）。

## 总览

npm workspaces monorepo，3 个包 + 1 个冒烟脚本：

```
packages/
├── shared/     IPC 契约层（纯类型 + 通道常量，三方共享）
├── backend/    纯 Node；pi SDK 适配层（唯一 import pi 的地方）
└── desktop/    Electron 应用（main / preload / renderer）
scripts/smoke-backend.mts   真实 SDK 冒烟测试（npx tsx 运行，需 AI_OPS_API_KEY）
scripts/smoke-error-events.mts  统一报错系统冒烟：本地 HTTP 伪造 provider（401/429）驱动 PiBackend，验证 turn_end stopReason=error / auto_retry 事件序列 / jsonl 持久化（零凭证、离线）
scripts/replay-trace.mts    事件 trace 重放（读 traces/trace-*.jsonl → reduceEvent → 输出最终消息；--last 自动找最新）
scripts/replay-evaporation.mts   上下文蒸发离线 replay 调参（读会话 jsonl 副本主链重建 → 逐 step 模拟 spec 的四级水位线蒸发，mono/naive 两变体对照 cache 失效；产出误杀率/体积曲线/T3 频率。默认数据指 .local/replay-data/sessions 副本，指向正式 ~/.pi/agent 会直接 abort；结论文档 .local/agent-work/handoff/evap-replay-results.md；网格窗口档 = 128K 定稿 + **160K/256K budget 补核**（结论在 .local/agent-work/plan/context-evaporation.md §2）+ 200K 外推 + 1M + t6085 定稿档；`--core` 开关 = mono 模拟改 import backend 蒸发核心驱动，离线/在线同构验证——基准 mono-p8k-t60-w128k 与线上实现逐字节一致）
scripts/smoke-evaporation-ui.mjs   蒸发设置二态 CDP 冒烟（dev 实例带 --remote-debugging-port=9224 运行后执行：全新 settings.json 默认蒸发/二态控件渲染/切 off·回切写侧清遗留 acpCompressionEnabled 键/派生回读与 UI 选中态一致，走 ~/.pi/agent-dev 隔离，结束后恢复现场）
scripts/shoot-rail.mjs      SessionRail 动画**确定性逐帧截图**（CDP `Page.captureScreenshot` 拿合成器页面表面，不经屏幕/无需录屏权限；`getAnimations()` pause 后 `currentTime` 钉帧零竞态；phase=enter/leave/sweep；需 dev 带 `--remote-debugging-port=9224` 运行且轨道已开、≥3 会话）
```

依赖补丁：`patches/` + patch-package（root `package.json` devDep + `postinstall: "patch-package"`，npm 11 下 root 自己的 postinstall 不被拦截）。目前一处：`thinking-orbs+0.3.1.patch` —— 移除 ThinkingOrb 组件的 IntersectionObserver+visibilitychange 双事件门控（Win11 上恢复事件丢失会让 rAF 循环永久停摆、状态行 orb 冻结；裸 rAF 在页面 hidden 时 Chromium 自动暂停/恢复续跑，语义不变）。改补丁：手改 `node_modules/thinking-orbs/dist/index.{es.js,cjs}`（两份同改）→ `npx patch-package thinking-orbs`；升级 thinking-orbs 前先重评补丁是否仍需要。

数据与凭证：`~/.pi/agent/`（sessions/*.jsonl、auth.json、models.json、trust.json 项目信任记录），与 CLI pi 共享。**dev/预览态隔离**：main 入口 `dev-agent-dir.ts` 把 `PI_CODING_AGENT_DIR` 重定向到 `~/.pi/agent-dev/`（SDK `getAgentDir()` 实时读该环境变量、无缓存），并从正式目录一次性种子拷贝 auth/models/settings/permissions/trust 五个小配置（目标已存在跳过）；正式目录零写入。会话事件 trace 在 `~/.pi/agent/sessions/<dir>/traces/trace-<sessionId>.jsonl`。应用自身数据在 Electron `userData/`：tabs.json、ui-state.json（模型/思考级别 + 主题/背景 + 左侧会话轨道开关）、backgrounds/（自定义背景图，renderer 经 `pi-bg://background/<文件名>` 协议加载，main 进程 protocol.handle 提供，文件名白名单防穿越）。

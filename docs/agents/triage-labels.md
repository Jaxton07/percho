# 分类标签

各技能用五个规范分类角色交流。本文件把这几个角色映射到本仓库实际使用的字符串。

| 规范角色 | 本仓库使用的写法 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需要评估这条议题 |
| `needs-info` | `needs-info` | 等报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 已充分说明，可交给 AFK agent 实施 |
| `ready-for-human` | `ready-for-human` | 需要人工实施 |
| `wontfix` | `wontfix` | 不做处理 |

本地 markdown 跟踪器没有真正的 label：把对应字符串写进议题文件靠上的 `Status:` 行即可。

技能里提到某个角色（例如“打上 AFK-ready 分类标签”）时，用上表右列对应的字符串。

要换词表，直接改“本仓库使用的写法”这一列。

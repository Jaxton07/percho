# SSH 远端开发

一个窗口同时连接本机和一台服务器。添加项目时选择“本机项目”或“远端项目”；项目和会话固定属于当时的环境，切项目不会断开另一边。远端项目列表、设置和通知显示所属环境；两边同名目录仍是两个项目。

## 首次连接

先在系统终端准备具体 SSH Host 别名，用系统 OpenSSH 确认密钥或 ssh-agent 认证和主机指纹，确保非交互连接无需输入。Percho 不接管密码、首次主机指纹确认或 SSH 配置文件。

在“设置 → 远端连接”填写别名，先点击“检测”图标。连接动作使用图标按钮，悬停可查看说明。平台、Node 与发行包前提及安装维护规则见[构建发布的 SSH 运行包](build-release.md#ssh-运行包)。点击“连接”后，如果缺包，桌面自动下载并展示版本与安装目录，确认后才上传安装。取消可停止本次准备；已有兼容服务会直接连接，不强制更新。

连接成功后输入服务器上的绝对项目目录，检查并信任后添加。路径按服务器文件系统解释，不需要本机 clone。删除连接只移除本机连接资料，旧项目仍保留原归属；另一台服务器的同名目录不会自动接管旧会话。

## 工作与设置

模型请求、工具、扩展、MCP 与子代理都运行在所属环境。设置页明确选择本机或远端，远端单独准备 provider、API key 和项目依赖。本机界面插件的授权范围覆盖整个工作台；本机 LAN 页面仅显示本机内容。具体信任与数据边界见[架构说明](architecture.md)。

远端普通文件只能复制路径后在服务器打开。Git、diff、图片和内容型会话导出使用所属后端；导出完整生成后再选择本机保存位置。首版没有通用远端文件浏览、下载或交互终端。

## 断线与停止

切到本机、断网、断开连接或退出桌面都不停止远端任务。需要批准或输入时服务等待；后台提醒不会自动切走当前项目。重连先核验服务端仍然待决的请求，再允许回答。构造中的会话也可能要求扩展输入，此时点击来源提醒即可处理，不需要创建另一份会话。

明确停止请在已连接的“远端连接”中选择“停止远端服务”，并等待退出确认。仅 SSH 退出或收到停止请求的确认，不代表资源已清理完。服务被其他桌面控制时返回占用，不会强行接管。

服务或主机崩溃后只恢复保存的历史，不自动重做上一条指令。提交后丢失确认会显示结果未知，可核查原回执、JSONL、轨迹与实际文件；没有记录也不能证明从未执行。不要据此重复发送有副作用的操作。
